# 异环内置只读抓取

状态：实验性（2026-11-19）

## 入口

`数据录入 → 异环 → 导入 NTE 导出`

内置 NTE Gacha Exporter CLI `1.2.9`，由 Electron 主进程调用。

## 两种模式

### 手动只读

- 不操作游戏。
- 用户自己在游戏里打开抽卡记录并翻到底。
- 在弹出黑色控制台按 `q` 结束。
- 软件检测到 JSON 后自动导入。

适合“不要动我游戏”的场景，但需要用户翻页。

### 自动翻页

- 软件控制游戏窗口自动翻页。
- 会操作鼠标键盘，因此不是严格只读界面操作；不会修改抽卡/账号数据。
- 开始前游戏需停在抽卡记录页，期间不要手动操作。
- 结束后自动导入。

## 权限

pktmon 抓包需要管理员权限。首次启动会弹 Windows UAC；允许后 CLI 以管理员身份运行。二游档案不保存管理员凭据。

## 数据

- 输出暂存 `data/nte-captures/nte-<mode>-<time>.json`。
- 只读取游戏封包，不上传。
- 导入后只保存 S 级；低稀有度用于总抽和垫抽计算。
- 角色池里的弧盘按 `itemId=fork_*` / `弧盘·` 名称拆到武器类型，不再混进角色。
- 角色名会去掉 `角色·` / `弧盘·` 前缀；同一时间、同一物品的旧记录会去重。
- 弧盘 ID 统一小写，避免大小写不同造成同一条弧盘重复。
- 导入后写回各池当前垫抽，并关闭“垫抽未知”标记。
- 文件可由用户自行删除。

## 限制

- 依赖 NTE Gacha Exporter CLI 和游戏封包格式，游戏更新/反作弊调整可能失效。
- 需要 PC 客户端 `HTGame.exe`。
- 手动模式不会自动翻页；自动模式需要游戏窗口前台。
- 抓包可能被安全软件拦截；这是本地只读流量，不注入游戏。
