# 小黑盒实验导入

状态：实验性（v2.00，2026-11-19）

## 能力

桌面版在「数据录入 → 小黑盒」打开一个隔离的小黑盒窗口：

1. 用户自己登录小黑盒。
2. 用户打开对应游戏的抽卡/祈愿分析页。
3. 软件只截取该窗口的 JSON 响应到内存。
4. 点「采集当前数据并导入」，按字段识别最高稀有度记录并合并到当前游戏档案。
5. 关闭窗口后清除捕获数据和临时会话。

支持所有游戏的数据录入页卡；实际能否拿到数据取决于小黑盒是否为该游戏提供网页版抽卡分析。

## 隐私与安全

- 不保存小黑盒密码、验证码、Cookie 或登录 token。
- 捕获数据只在主进程内存中，关闭窗口即清空。
- 不写小黑盒，不自动登录，不自动翻页。
- 跳过 URL 中包含 `login/auth/token/captcha/sms/passport/oauth` 的响应。
- 使用独立非持久化 `partition`，关闭时清理存储。

## 局限

- 小黑盒没有公开抽卡 API，H5 页面和私有接口改版可能导致失效。
- 页面必须已经加载出抽卡分析数据；只打开社区首页捕获不到记录。
- 字段识别是兼容性启发式，若小黑盒改字段，可能提示“没有识别出记录”。
- 总抽数只有响应里明确带 `total` 等统计字段时才会写入；否则只导入高星记录。
- 不绕过小黑盒登录/风控；需要用户手动完成登录。

## 回退

- 明日方舟：继续使用「导入小黑盒 JSON」。
- 终末地：本机链接/粘贴链接。
- 异环：NTEUID。
- 其他游戏：截图 OCR / 手动 / Excel。

## 关键文件

- `electron/main.cjs`：隔离窗口、debugger 网络捕获、内存清理。
- `electron/preload.cjs`：`window.desktop.heybox`。
- `src/api/heybox-live.js`：字段识别与合并。
- `public/app.js`：小黑盒页卡和操作按钮。
