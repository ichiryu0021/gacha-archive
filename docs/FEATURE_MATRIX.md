## 说明

- 崩坏3 / 未定没有公开抽卡接口，自动同步类功能没有数据源；手动、Excel、分享、版本判定必须保持可用。
- 明日方舟使用森空岛扫码 + 官方寻访历史接口；官方不返回 UP 信息，因此不做自动 UP/歪判定。
- 终末地优先读取游戏日志里的 `ef-webview` 链接，也支持森空岛；国际服支持 `gryphline` 域名。
- 异环使用塔吉多官方接口，只返回已出 S 的明细和 S 区间抽数，官方约保留 180 天；B 服 / 国际服暂不支持。NTEUID JSON 导入作为长期归档兜底。
- 三款新游戏只归档最高稀有度（记为 `rank=5`），界面显示“六星”或“S级”；手动/Excel/分享保持可用。
- 新游戏版本表和图鉴暂未补齐；以后新增功能，先更新本矩阵，再写代码。
