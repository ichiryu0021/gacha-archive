# 二游档案 v2.00

这是一个大版本，也是更新仓库的迁移点。

## 新增

- 明日方舟、明日方舟：终末地、异环三款游戏。
- 三款游戏全部并入「数据录入」：官方同步、截图 OCR、手动/Excel、历史汇总。
- 异环完整 NTE Gacha Exporter 导入，以及内置手动只读 / 自动翻页抓取。
- 小黑盒实验导入。
- 图鉴：方舟 404 条、终末地 114 条、异环 79 条，全部带图。
- 异环常驻 S 判定与命中率。
- 每游戏独立主题色。
- 分享总结生成中预览与图片加载超时保护。

## 仓库迁移

- v2.00 同时发布在旧仓库 `miyou-archive` 和新仓库 `eryou-archive`。
- 旧仓库只保留 v2.00 及以前内容，随后封存。
- v2.00 以后只更新 `eryou-archive`。
- v2.00 安装包内的更新器已指向新仓库。

## 升级说明

- 旧版本直接检查更新即可；更新只替换程序文件，不覆盖 `data/`。
- 大版本也可以下载完整包覆盖安装。
- 用户数据、备份、登录态不会被更新删除。

## 已知说明

- 异环官方塔吉多接口只提供已出 S 的覆盖抽数；完整总抽需导入 NTE Gacha Exporter 或使用内置抓取。
- 异环内置抓取首次使用需要 Windows 管理员权限（pktmon 抓包）。
- 小黑盒导入为实验功能，页面改版后可能失效。
