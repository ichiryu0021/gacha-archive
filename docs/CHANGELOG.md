## 2026-11-19 · v1.10 维护

### 账号与登录

- 右上角账号入口改为双页卡：
  - **游戏账号**：原神 / 星铁 / 绝区零 / 明日方舟 / 终末地 / 异环，独立游戏卡片，直接同步。
  - **账号登录**：米游社 / 森空岛 / 塔吉多。
- 森空岛绑定修复：`binding_list` 改用 `oauth2/v2/grant` 换取的 web token，不再误用扫码通行证 token，解决“已登录但没有绑定角色”。

### 数据录入

- 取消独立的「第三方同步」页面；官方同步、截图 OCR、手动/Excel、历史汇总统一收进各游戏的「数据录入」。
- 明日方舟：官方同步 / 导入小黑盒 / 截图 / 汇总 / 手动。
- 终末地：官方同步 / 截图 / 粘贴链接 / 汇总 / 手动。
- 异环：官方同步 / NTEUID / 截图 / 汇总 / 手动。
- 截图 OCR 的标题、保存按钮和星级识别按游戏显示「五星 / 六星 / S 级」，补 `六星 / 6星` 识别。

### 小黑盒

- 方向修正为**从黑盒导入**，不是导出。
- 明日方舟支持小黑盒 JSON：
  - 读取完整寻访序列；
  - 只落库六星；
  - 按完整序列计算六星垫抽和总抽数；
  - 合并入现有档案，不覆盖旧记录。
- 小黑盒 JSON 不提供 UP/歪标记，导入后仍由本地卡池数据库判定。

### 卡池与图鉴

- 新增 `src/data/banners.json`，保存当前/近期卡池和 UP 名单（截止 2026-11-19）：
  - 明日方舟：将雪投火、常驻标准寻访、幽境狩人。
  - 终末地：烟火邀星河。
  - 异环：电子人之梦。
- 新增 `src/data/catalog-arknights.json`、`catalog-endfield.json`、`catalog-nte.json`，用于手动录入、OCR 和名称匹配。
- UP 判定：
  - 按记录时间、卡池类型和名称匹配 banner；
  - 命中 UP → `win`；明确名单内非 UP → `loss`；
  - 未命中卡池表 → 保持未知，不强行判定。
- 数据录入的官方同步卡片显示当前卡池和 UP 名单。

### 小黑盒实验导入

- 新增桌面版「小黑盒」数据录入页卡，支持所有游戏。
- 打开隔离的小黑盒窗口，由用户手动登录并打开对应游戏抽卡分析页。
- 只截取页面 JSON 响应到内存，关闭窗口清除会话和捕获数据；不保存小黑盒密码或 Cookie。
- 捕获后按字段识别角色、稀有度、时间、卡池和抽数；明日方舟同时兼容已有 JSON 结构。
- 实验性功能，依赖小黑盒页面/私有接口，改版后可能失效；失败回退 JSON 导入。

### 图鉴

- 第三方图鉴补齐图片、武器/弧盘和类型：
  - 明日方舟：404 个角色，全头像。
  - 终末地：34 个角色 + 80 件武器，全图标。
  - 异环：26 个角色 + 53 个弧盘，全图标（来源改为 nanoka NTE 数据站 1.5.4）。
- 图鉴页按游戏显示正确稀有度：明日方舟/终末地六星制，异环 S/A/B。
- 图鉴支持自动检查更新（7 天节流）和手动「同步图鉴」；失败保留旧快照。
- 数据/图片来源和官方 wiki 签名限制见 `docs/CATALOG_SOURCES.md`。

### 异环命中率与总抽

- 常驻 S 级：九原、早雾、白藏、达芙蒂尔、法帝娅、哈索尔。
- 限定池中，常驻 S 判为歪，其余 S 判为 UP；命中率按已判定 S 数计算，不再把未判定的武器/常驻记录算进分母。
- 官方接口只返回已出 S 的区间抽数，没有账号完整总抽；界面改为“已覆盖抽数”，并提示未出 S 的垫抽和窗口外记录不可得。

- 终末地：青绿 + 工业米色主题。

### 分享总结修复

- 分享图生成改为先弹出预览窗口并显示“正在生成”，不再点击后长时间无反馈。
- 图片加载限制为角色/武器各 6 张，单张 5 秒超时；优先 CORS 直连，失败回退本地代理。
- 分享图图片缓存，重复打开更快。
- 生成完成前复制/保存按钮禁用，避免拿到空图。

### 异环抓取修正

- 修复自动抓取导入后角色/弧盘混在一起：角色池内的弧盘按 `fork_*` / 弧盘名称归为武器。
- 修复 `角色·` / `弧盘·` 前缀导致同一记录重复。
- 修复导入后 `perType.five` 归零、当前垫抽仍显示未知。
- 启动时自动修复旧 NTE 重复记录并重新分类；重复 S 只保留导出记录。
- 修正运行态 `data/catalog-nte.json` 仍是旧 62 条的问题；新角色图标现在能正常显示。
- 弧盘 ID 大小写统一（`fork_Butterfly` / `fork_butterfly`），避免同一弧盘重复。
- 自动录入面板改为高亮首选，手动只读降为兜底入口。

### 异环内置抓取

- 内置 NTE Gacha Exporter CLI 1.2.9（MIT，`tools/nte-gacha-exporter`）。
- 数据录入 → 异环 → 导入 NTE 导出新增两种模式：
  - 手动只读：不操作游戏，用户翻页后在控制台按 `q` 结束。
  - 自动翻页：用户确认后由软件控制游戏翻页。
- 抓取结果自动解析导入，完整总抽和 S 垫抽一次算清。
- 首次使用需要 Windows UAC 管理员权限；pktmon 只读取本机游戏封包，不上传。

### 异环完整抽卡记录

- 新增「导入 NTE 导出」页卡，支持 NTE Gacha Exporter 的 `nte-gacha-export` JSON。
- 该文件来自游戏封包/自动翻页，包含完整抽卡流水；导入后可得到完整总抽数、各池抽数和 S 垫抽。
- 入库仍只保存 S 级，低稀有度用于总抽/垫抽计算，不逐条写入档案。
- 只有塔吉多官方同步时仍显示“已覆盖抽数”；导入完整导出后显示真实总抽数。
