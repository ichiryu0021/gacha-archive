# 「机能」MECHANICAL · 设计语言

> 非官方视觉方案。以《明日方舟：终末地》一类的工业编辑语言为参照：纸墨感、直角、技术标注、单一信号色；不复制任何游戏素材。

## 1. 概念

把「二游档案」想象成一台放在机库里的本地终端：

- 界面是**仪表**，不是海报。数据按工程图纸的秩序摆放，重要的数字大、次要的说明小。
- 面板是**机加件**：直角、1px 边框、四角括号、编号和序列号。
- 柠檬黄是**信号色**，只在交互与关键读数上出现；它不是装饰底纹。
- 每个游戏的固有颜色被保留为**机体涂装色**，只进入数据、图表和该游戏的标记。

关键词：`INDUSTRIAL` `INSTRUMENT` `RIGHT-ANGLE` `HAIRLINE` `SIGNAL-YELLOW` `TABULAR` `LOCAL-ONLY`

## 2. 三条硬规则

1. **纸墨是主体，信号色是标点。**
   大面积使用石墨黑、钢灰和骨白；黄色用于主操作、选中态、焦点、关键角标与警示。
2. **全直角。**
   圆角归零；容器、按钮、标签、图标框全部直角，只有命中率圆环这类必须为圆形的图形保留圆形。
3. **数字等宽，标签等宽大写。**
   所有数字开 `tabular-nums`；技术标签使用等宽字体、宽字距、小字号。

## 4. 字体

| 用途 | 字体 | 字号 / 字重 | 字距 |
| --- | --- | --- | --- |
| 大数字（总抽数） | Bahnschrift 300 | `clamp(50px, 7vw, 82px)`（同经典） | `-.03em` |
| 页面标题 | Bahnschrift 600 + 雅黑 600 | `clamp(26px, 3vw, 38px)`（同经典） | `.03em` |
| 统计数字 | Bahnschrift 300 | `27px`（同经典） | `-.02em` |
| 卡片标题 | 雅黑 600 | `15.5px`（同经典） | `.07em` |
| 正文 | Segoe UI Variable / 微软雅黑 | `13–14px`（同经典） | `0` |
| 技术标签 | Cascadia Mono 500 | `10.5–11.5px`（同经典） | `.12–.26em` |
| 英文副题 | Cascadia Mono | `10–11.5px`（同经典） | `.16–.2em` |

- 所有数字使用 `font-variant-numeric: tabular-nums`，避免跳动时横向抖动。
- 中文标题使用系统黑体；Bahnschrift 只承担数字与拉丁展示字。
- 技术标签统一大写（英文），中文标签保持原样但缩到 9–10px。
- **字号与经典完全一致**：主题 CSS 不再覆盖应用内字号，只改变字体、字重、字距与颜色；1440 下实测 `h1 38 / Hero 82 / 卡片标题 15.5 / 统计 27 / 导航 15.5 / 页签 14.5 / 表头 10.5px`，黑白两版与经典逐项相等。
- **机能 · 黑**：标题 / 大数字 / 关键读数用黄色 `#f2d35f`，正文用暖骨白，按钮实底用 `--m-bone`。
- **机能 · 白**：主字 `#2b312d` 带纸面压印阴影（`0 1px 0 #fffdf7, 0 2px 5px rgba(28,32,28,.12)`）；大数字用更硬的两层白高光；技术标签只用 1px 硬阴影，避免 ClearType 发糊。

## 5. 几何与纹理

| 元素 | 规范 |
| --- | --- |
| 圆角 | `0`（少数圆形对象除外） |
| 发丝线 | `1px`；线色 `rgba(236,233,221,.09)` |
| 卡片内边距 | `18px`；卡片间距 `14–15px` |
| 卡片角标 | 四角 `8px × 1px` 的 L 形括号，内缩 `6px`，透明度约 `.55` |
| 页面背景网格 | `24px` 细网格 + `120px` 主网格；径向遮罩淡出 |
| 顶部警示带 | 视口顶部 `2px` 斜纹（黄 / 透明） |
| 扫描线 | `1px / 3px` 的固定叠加，极低透明度，仅置于内容层下方 |
| Hero 瞄准弧 | `376px` 圆环，遮罩只保留外圈刻度与一圈内环 |

背景网格只在画布与空状态里可见，不进入卡片内部；卡片内部保持干净，避免读数和网格互相干扰。

## 6. 组件规范

### 6.1 侧栏

- 宽 `240px`；右侧 1px 发丝线；底部 `SYS // LOCAL ARCHIVE` + 版本。
- 品牌：`38px` 方形徽标，柠檬黄边框，底部一条 3px 斜纹；字标 `二游档案` + `GACHA ARCHIVE` 等宽大写。
- 导航上方有 `MODULE INDEX` 技术标签；每项带 `01–05` 编号。
- 选中态：左侧 2px 黄色标尺 + 从黄到透明的浅色渐变；不是圆角胶囊。

### 6.2 顶栏

- 高 `72px`；底部 1px 线 + 一排短刻度（两端淡出）。
- 游戏页签是一个直角分段控件；每项右侧 1px 分隔线；激活项底部 2px 机体色线。
- 页签圆点改为 4px 旋转 45° 的方块。
- 右侧：刷新 → 账号。账号上方显示 `OPERATOR` 微标签；主题切换只在设置页。

### 6.3 页面标题

- 英文 eyebrow：`// OVERVIEW · FIVE-STAR ONLY`，等宽、9px、`.2em`。
- 标题前有一个 `01` 编号盒（26×22，黄边 + 黄字），随页面切换自动编号。
- 页面编号使用 `:has()` 根据视图内容判定：Hero / 记录工具栏 / Tabs / 图鉴网格 / 设置网格。

### 6.4 卡片

- 平面渐变 `#151a16 → #111512`，1px 边框，顶部略亮。
- 卡片标题：3px 黄色标尺 + 中文标题 + `// ENGLISH` 等宽小标签；标题下方 1px 分隔。
- 卡片四角有 L 形括号；没有阴影、没有毛玻璃。

### 6.5 Hero

- 背景：64px 工程网格 + 右上角黄色柔光 + 深色渐变。
- 大数字 300 字重、极紧字距；右侧有一条由 13px 间距刻度构成的水平标尺。
- 右上角最新五星图标：64px 直角框，内部再缩进 3px 加一圈黄线。
- 瞄准弧：以最新物品为视觉中心的刻度圆环，局部被卡片裁切，像仪表窗口。
- 主按钮是**奶油实底 + 黑字**；悬停转为柠檬黄，不变形、不发光。

### 6.6 命中率圆环

- 92px；`conic-gradient` 画命中比例，黄色。
- 上层用 `repeating-conic-gradient` + 径向遮罩切成 80 段刻度，形成机械表盘感。
- 中心：数字 21px Bahnschrift + `FIVE STARS` 7.5px 等宽。

### 6.7 垫抽 / 进度条

- 轨道 5px，直角；填充用机体色渐变；上层每 10px 一道暗色刻度，形成分段电量条。
- 记录页的垫抽条高 18px；左侧是 40×24 的骨白数字块（黑字），像仪表上的贴标读数。
- 过高垫抽用暗红 → 橙红；低垫抽用暗绿 → 草绿；不再使用霓虹高亮。

### 6.8 统计卡

- 四张卡：`S01–S04` 右上角编号；左侧 2px 机体色竖线。
- 数值 30px Bahnschrift；注释 9px 等宽；不换行、超长省略。

### 6.9 表格

- 表头深色底 + 等宽 9px 大写标签；正文 `nowrap`，数字列等宽。
- 行悬停：极轻的黄底；不使用圆角。
- 移动端表格保持 `min-width: 720px`，在 `.table-wrap` 内横向滚动，并显示 6px 滚动条；不再挤压成竖排单字。

### 6.10 记录页

- 每个卡池是一块 `POOL //` 面板；行间发丝线。
- 记录行：版本 + 来源 → 图标 + 名称 → 骨白垫抽块 + 分段条 + UP/歪 + `/cap`。
- UP 用黄边；歪用红边；欧 / 连金用黄底小标签。

### 6.11 数据录入

- Tab 自动编号 `01–07`；激活项底部 2px 黄线。
- 扫描卡片：顶部 2px 机体色；标题旁方形状态点；按钮为直角描边。
- 上传区：1px 虚线 + 直角；悬停变黄；技术说明使用等宽 9.5px。
- 提示条：左侧 2px 色条 + 低透明渐变；黄 / 青 / 红三种语义。

### 6.12 图鉴

- 8 列密集网格（118px 起），卡片 8px 内边距，图片区直角。
- 稀有度角标是左上角黑底黄字小标签；已拥有标记是 16px 黄色方块 ✓。
- 悬停：边框转黄，背景略亮，不做位移。

### 6.13 设置

- 数据管理、游戏顺序、运行信息、软件更新沿用原组件，改为直角、等宽 kv、虚线分隔。
- 顶部运行时注入「界面主题」卡：两枚预览块 + 使用中标记；说明文字指向独立主题接口。

### 6.14 空状态 / 弹窗 / Toast

- 空状态：1px 虚线框，左上 `NO DATA // WAITING FOR ARCHIVE`，右上黄色斜纹，中央 58px 旋转 45° 的菱形准星。
- 弹窗：`SYSTEM // DIALOG` 顶栏；直角；按钮直角；背景只做压暗，不做模糊。
- Toast：左侧 3px 语义色条；等宽 10.5px；直角。

## 7. 交互与动效

- **Hero 瞄准环**：`rotate` 30s 线性无限旋转 + `scale/opacity` 4.8s 呼吸；黑白共用一套 keyframes，只覆盖 `--reticle-min/max`。
- **命中率环**：入场 `scale .86 → 1`；JS 把内联 `--p` 从 `0%` 缓动到目标值，呼吸变量不影响弧线。
- **条状**：卡池条 / 垫抽条 / 月度柱 / 时间轴段用独立 `transform: scaleX/Y` 入场，错峰 30ms；记录页只给前 12 行做条动画。
- **数字**：Hero 总抽、命中率、统计卡、垫抽、月度、记录总数、卡池读数从 0 缓动到终值；先落 0 再计数，结束写回原始字符串。
- **圆盘 / 卡片**：命中率环、空状态 orb、统计卡、最近出金条目入场缩放；使用独立 `scale` 属性，不覆盖 orb 的 45° 旋转。
- **刻度尺**：Hero 数字下方刻度用 `clip-path` 从左到右“校准画出”，700ms，只播一次。
- **视图**：`opacity + translateY(4px)`，约 280ms；设置页主题卡随页面渲染出现。
- **降级**：`prefers-reduced-motion: reduce` 下移除 `.mecha-in`、`animation: none`，数字直接写终值；经典主题不挂动画类。
- **性能**：只动 `transform/scale/rotate/opacity/clip-path`；不使用 `filter`；`will-change` 只给 Hero 伪元素；`#view` 只观察 `childList`，不观察 `subtree/characterData`。

- 悬停：只改变颜色 / 边框 / 极轻背景，不做上浮。
- 按下主按钮：下沉 1px。
- 主题切换只在设置页卡片内完成；不再提供顶栏悬浮选择器。
- 不使用 `backdrop-filter` 毛玻璃；浮层允许深色投影。页面不使用大面积彩色弥散光，Hero 右上角的黄色柔光是唯一例外。

## 8. 可访问性

- 正文与次级文字满足 4.5:1 以上对比；黑版技术标签不低于 `#85816f`（约 4.6:1）；白版技术标签用 `#626a64`，不再沿用暗色 `#8a9089` 这种低对比值。
- 主按钮为骨白底黑字 / 黄色底深字；白版为深墨底纸色字 / 琥珀底深字，对比度高。
- 所有交互元素保留 `:focus-visible` 1px 黄色（白版琥珀）描边，偏移 2px。
- 白版文字阴影只用于纸底；输入框、表格密集数字、深色实底上不使用白阴影。
- 主题切换按钮有 `aria-label`、`aria-expanded`；主题选项有 `aria-pressed`。
- 面板支持 Esc 关闭；点击外部关闭。
- 颜色不是唯一信息：UP/歪同时有文字标签；过高垫抽同时有数值块。
- 移动端表格保留横向滚动，不通过缩小字号强行塞入。

## 9. 实现说明（独立入口 + 打包内置）

- **作用域**：黑 / 白共用 `html[data-theme="mecha"]` 结构，白版用 `html[data-theme="mecha"][data-mecha-variant="light"]` 覆盖；经典模式 `data-theme="classic"` 不加载任何视觉覆盖。浅色覆盖使用双属性前缀，避免输给暗色高特异性规则。
- **独立入口注入**：代理原服务，在 HTML 的 `<html>` 上写入 `data-theme` + `data-mecha-variant`，并在 head / body 末尾注入 CSS / JS。
- **打包内置注入**：`scripts/pack.cjs` 在打包完成后把 `theme.css` / `theme.js` 复制进 `resources/app/public`，并在打包后的 `index.html` 注入首屏 Cookie 引导、样式和脚本；原项目 `public/index.html` 不改。
- **首屏无闪**：独立入口由服务端返回主题属性；打包内置由 head 内联脚本读取 Cookie 后立即设置 `data-theme` / `data-mecha-variant`，再加载主题 CSS。
- **页面编号**：使用 `:has()` 判断当前视图内容（Hero、记录搜索框、Tabs、图鉴网格、设置网格），不需要改 `app.js`。
- **设置页卡片**：`MutationObserver` 监听 `#view` 的重新渲染；检测到 `.settings-grid` 后注入卡片，并在主题切换时同步选中态。
- **动效脚本**：`MutationObserver` 只观察 `#view` 的 `childList`；每次重渲染后 rAF 合并，给新节点加 `.mecha-in` 并启动计数 / 弧线；数字写 `firstChild.nodeValue`，不破坏 `<small>` 单位；classic / reduced-motion 早退。
- **持久化**：独立入口用 `/__theme/api/state`、`/__theme/api/theme` 写 `.theme-state.json`；打包内置用 `ga_theme` Cookie（`classic|mecha|light`），按 `127.0.0.1` 生效，存在 Electron 的 `data/electron/`，与随机端口无关。
- **降级**：浏览器不支持 `:has` 时页面编号不显示；不支持 `mask` 时圆环/网格细节减弱；功能不受影响。

## 10. 已知边界

- 分享总结 JPG 由原应用的 canvas 生成，本次不拦截、不重绘，因此保留原版圆角与配色。若要做机能版分享图，应单独实现绘制器，并复用原应用的统计口径。
- 源码开发运行（`npm start` / `npm run desktop`）不自动注入主题；只有 `npm.cmd run pack` 生成的开发版会内置。浏览器预览请用独立主题入口。
- `dist\` 里已有的 v2.00 zip 是集成主题前的产物；重新压缩后才会带内置主题。
- 字体依赖 Windows 环境；其他平台使用回退字体，字距与宽度会有差异。
